Human Escalation Points
• Client requests human agent → immediate escalation
• OCR cannot determine validity → office staff review (< 2h)
• In-person meeting request → owner approval (< 4h)
• AI summary generated → agent accuracy check (< 24h)
• Task assigned post-summary → staff member executes
Document Validation Rules
• ID photo: must be readable via OCR + valid format
• Power of attorney: file must be attached (optional)
• Invalid doc → auto-request re-upload immediately
• Loop continues until all required docs are valid
• Form link sent as alternative collection method

CLIX | Integration Specifications
Required API connections, capabilities, and endpoint signatures
💬
WhatsApp Business API
Messaging Platform
Connects to multiple numbers (personal, office, staff). Must support media messages (images, PDFs) for document collection. Handles automated responses, reminders, and escalation routing.
send_message(phone, text, media?)
on_message(webhook_handler)
get_unread(phone_number)
send_template(phone, template_id)
📅
Google Calendar
Scheduling Engine
Generates booking links for clients, checks availability, creates events, triggers pre-meeting reminders. Supports multiple calendar accounts per staff member.
create_event(calendar, details)
check_availability(calendar, range)
get_upcoming(calendar, days_ahead)
generate_booking_link(calendar, config)
🏢
BAFI System
Insurance Management
Core insurance management platform. Used for client records, policy data, product info. Integration depends on BAFI's available API or export capabilities.
get_client(client_id)
get_policies(client_id)
check_status(policy_id)
update_client(client_id, data)
✉️
Email System
Communication Channel
Monitors all team email accounts. Detects pending emails, identifies action items, feeds into task engine. Also sends summaries and form links to clients.
scan_inbox(account, filters)
get_unread(account)
send_email(to, subject, body, attachments?)
mark_read(message_id)
